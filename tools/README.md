# nagoya_maple_story

單一 `index.html` 的旅遊行程網站，直接雙擊就能看；放到 GitLab Pages／GitHub Pages 也不用改。

## 購物清單同步（Google 試算表）

沒設定時，清單只存在該裝置的瀏覽器。設定後兩個人的手機會看到同一份，勾「買到了」也會同步；沒網路時先顯示上次的資料，改動會排隊，連上線後自動補送。

### 第一次設定（約 5 分鐘，只要做一次）

1. 到 [sheets.new](https://sheets.new) 建一個新的 Google 試算表，名稱隨意（例如「楓葉物語 購物清單」）。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡預設的內容全部刪掉，貼上 `tools/Code.gs` 的全部內容，按 💾 儲存。
4. 右上 **部署 → 新增部署作業**：
   - 類型：選齒輪 → **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按 **部署**，第一次會要求授權，選你的 Google 帳號 → 進階 → 前往（不安全）→ 允許。
5. 複製出現的 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）。
6. 打開網站 → 購物清單 → ⚙️ → 貼上網址 → **儲存並連線**。第一次會問要不要把目前清單上傳，選確定。
7. 同行者的手機打開同一個網站，⚙️ 貼同一個網址即可。

### 之後要改 Code.gs

改完要 **部署 → 管理部署作業 → ✏️ → 版本選「新版本」→ 部署**，網址不會變。

### 記帳功能也用同一個網址

記帳會自動建立另一個工作表 `expenses`，不用另外申請。**如果你已經部署過舊版 Code.gs，要把新的 Code.gs 整份貼上去覆蓋，再用「部署 → 管理部署作業 → ✏️ → 新版本」重新部署**，否則記帳區會顯示「Apps Script 還是舊版」。

### 注意

- 「所有人可存取」代表知道網址的人都能讀寫這份清單。網址很長很難猜，但不要公開貼出去。
- 試算表本身也可以直接在手機 Google 試算表 App 裡改，網頁按「↻ 重新整理」就會拿到。
- Apps Script 每次回應約 1–3 秒，所以勾選後狀態列會先顯示「同步中」。

## 日文小記的離線音檔

網站的 🔊 按鈕會先找 `audio/<id>.mp3`，有就直接播放（離線可用）；沒有就退回瀏覽器內建語音（需裝置有日文語音，iPhone 在「設定 > 輔助使用 > 朗讀內容 > 語音」可下載）。

產生音檔，二選一：

**A. Mac 內建語音（離線、免安裝）**

```bash
cd ~/Desktop/nagoya_maple_story && bash tools/make_audio.sh
# 想換聲音：VOICE=Otoya bash tools/make_audio.sh
```

需要先在「系統設定 > 輔助使用 > 朗讀內容 > 系統語音 > 管理語音」下載日文語音（Kyoko 或 Otoya）。有 ffmpeg 會輸出 mp3，沒有則輸出 m4a 並自動改網頁副檔名。

**B. edge-tts（線上，聲音較自然）**

```bash
pip install edge-tts
python3 tools/make_audio_edge.py
```

兩種都會讀 `index.html` 裡的 `phrases-data`，之後在網頁新增句子，重跑一次就好。

## 修改內容

所有資料都在 `index.html` 底部的 `<script>`：

- `DAYS`：每日行程（時間軸、備注、建議餐廳）
- `SHOP`：購物清單的預設項目（連線試算表後以試算表為準）
- `GUIDES`：攻略提醒
- `phrases-data`（JSON）：日文小記
- `HOTELS`、`TODO`：住宿與各種清單

待辦、行李、每日備注的打勾狀態存在瀏覽器 localStorage，換裝置不會同步；只有購物清單會走試算表。
